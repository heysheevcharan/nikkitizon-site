# nikkitizon.com

Astro site, deployed on Vercel. Content is edited at https://nikkitizon.com/admin (Decap CMS, GitHub login).

- Site name / Twitter handle / Substack embed: `src/site.config.ts`
- Homepage intro + links: `src/content/home/home.mdx` (or /admin → Home)
- Posts: `src/content/blog/`, pages: `src/content/site-pages/`

```sh
npm install
npm run dev     # http://localhost:4321
npm run build
```
